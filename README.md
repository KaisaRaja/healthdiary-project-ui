# HealthDiary Frontend

HealthDiary on veebipõhine rakendus, mille eesmärk on patsiendi terviseandmete sisestamine, jälgimine ja kuvamine.

See repositoorium sisaldab **rakenduse kasutajaliidest** (frontend), mis suhtleb eraldi backend-serveriga.

---

## Projekti eesmärk

- Võimaldada kasutajal lisada ja vaadata terviseandmeid (nt palavik, ravimid)
- Seostada andmed konkreetse patsiendiga
- Kuvada selge ja kasutajasõbralik terviseandmete ajalugu
- Luua mugav ja intuitiivne liides tervise jälgimiseks

---

## Vali IT lõpuprojekt

See projekt valmis **Vali IT tarkvaraarenduse programmi lõpuprojektina**, eesmärgiga rakendada õpitud oskusi pärisrakenduse arendamisel. Frontendi osa valmis Vue.js abil.
